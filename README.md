# rotate-rs

rust日志轮转库，可以按时间、大小、时间+大小三种方式进行轮转，支持gz压缩格式

## 归档命名

默认模板 `{dir}/{name}{sep}{date}{sep}{counter}{sep}{suffix}`，其中：

- 活跃文件恒为 `logs/app.log`；
- `{date}` 默认 `%Y-%m-%d-%H-%M-%S`（秒级精度）；
- `{counter}` 是**重名去重后缀**，不是"归档序号"：
  - 同一 `{date}` 内**首次**轮转 → `logs/app.2026-10-11-14-15-03.log`（不带序号）；
  - 该名字已被占用（同一秒内发生第二次及以上轮转）→ 依次补 `logs/app.2026-10-11-14-15-03.1.log`、`.2.log`…

`date` 精度越粗，出现序号的可能性越大；精度取到秒且轮转间隔 ≥ 1s 时，序号基本只在
异常场景（间隔 < 1s、size 阈值极小、同目录多 Writer）下出现。
